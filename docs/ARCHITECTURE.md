# kursk-news.net — архитектурная модель и план улучшений

Снято 20.11.2026: главная, все ленты, рубрики, карточка новости, служебные
страницы, RSS, sitemap, robots, внутренний API. Кодировка сайта windows-1251,
статика отдаётся с соседнего домена news-kursk.ru.

## 2. Функциональные блоки

### 2.1 Сквозные (на всех страницах)

**Шапка.** Логотип (275×46), поисковая форма Яндекса, иконки соцсетей (TG, VK,
OK, RSS — реализованы как `<div onclick>`, не ссылки), бургер, меню: Главная,
Лента, Важно, Официально, Топ, Видео, СМИ, Паблики, Мнения, Лонгриды,
«Категории» (дропдаун, 7 рубрик), Происшествия, О нас.

**Правая колонка «Лента новостей».** Липкая (sticky), 9 табов: Лента, Важно,
Топ, Видео, СМИ, Официально, Паблики, Мнения, Лонгриды. Активная панель
заполняется сервером, остальные — пустые контейнеры, содержимое приходит
AJAX-ом. Два вида строк:
- новость: время + миниатюра 100×65 + заголовок;
- inline-сообщение: время + текст + источник, без ссылки на статью (так
  публикуются оперативные предупреждения и посты пабликов).

**Подвал.** Копирайт, e-mail, 5 юридических ссылок.

**Монетизация.** Рекламный слот `.rtb_style_1` (на карточке — внутри потока
контента), вставки RTB-скриптов.

### 2.2 Главная

| Блок | Что внутри | Замечание |
|---|---|---|
| Hero «Главные новости за сутки» | 1 крупная карточка: заголовок, дата, лид | единственная новость «за сутки» |
| «Топ» | 20 карточек: миниатюра, заголовок, описание, время | дублирует `/top` |
| Пагинация | `<ul id="paging" data-scroll="1"></ul>` — пустой | всё делает JS |
| Правая лента | 9 табов | дублирует меню |

### 2.3 Ленты и рубрики

Одинаково: `h1` → список карточек → пустой `#paging` → правая лента.
Карточка: миниатюра `_100x65.webp` (+`@2x`), заголовок, лид, обрезанный по
символам, время `ЧЧ:ММ` без даты. Каждая 3–4-я строка — inline-сообщение без
ссылки. Подгрузка: `GET /api/<feed>?id=<последний id>&type=<key>&page=<n>`,
ответ — HTML + `==========<nextId>`.

### 2.4 Карточка новости

`h1.title` → `news_meta`: дата (`20 ноября 2026, 18:14`) и хлебные крошки
рубрики → `articleBody`: абзацы, картинки, вставки, цитаты → шеринг (ВК, ОК,
МАКС, Telegram) → «Источник: …» → блок подписки на паблик в ОК → реклама →
«Топ» из 10 карточек → правая лента.

### 2.5 Информационные страницы

Пять страниц в одном шаблоне (`about-us`, `contacts`, `editorial-policy`,
`privacy`, `rules`): заголовок + текст, без оглавления и даты обновления.

### 2.6 Служебные

RSS (200 записей, `content:encoded` с `<picture>`), три sitemap-файла,
robots.txt, `/api/` (фрагменты), `/api/stat` (счётчик), страница 404.

## 3. Модель данных

```
categories ──┐
             ├─< articles >── article_tags ── tags
sources ─────┘        │
                      ├─< article_images
                      └─< feed_items (inline-сообщения)
pages (статические)
```

`articles`: id, slug (URL), title, lead, body, category_id, source_id,
published_at, cover, views, is_top, is_important, is_video, is_longread,
is_opinion, reading_time.

`feed_items`: id, kind (`news|alert|social`), title, body, source_id,
article_id (nullable), published_at, pinned, severity.

`categories`: slug, title, description, sort.
`tags`: slug, title; `sources`: slug, title, kind (`media|tg|gov`).

## 4. Слабости

### Навигация и поиск
1. Поиск — чужой виджет; `/search/` без параметров отдаёт **404**, выдача не
   индексируется, нет подсветки и пустого состояния.
2. Нет страниц тегов, источников, авторов — весь контент доступен только через
   ленту и 7 рубрик.
3. Меню и табы правой колонки дублируют друг друга девятью одинаковыми
   пунктами; «Категории» — единственный дропдаун и работает только мышью.

### Лента
4. Бесконечная прокрутка без состояния в URL: вторую страницу нельзя
   переслать, «назад» теряет позицию, без JS дальше первой порции не уйти
   (`#paging` пустой на сервере).
5. Заголовки/лиды обрезаются по символам — многоточие посреди слова.
6. Время только `ЧЧ:ММ` без даты и группировки по дням — у старых записей
   непонятно, когда это было.
7. Миниатюры с `alt=""`, без `srcset`/`sizes`, без явных размеров.
8. Оперативные предупреждения («авиационная опасность») лежат в общем потоке
   наравне с бытовыми новостями, без закрепления и без визуального приоритета.

### Карточка
9. Нет времени чтения, оглавления у лонгридов, галереи, связанных по теме
   материалов (только глобальный «Топ»), кнопки «сохранить», управления
   размером шрифта.
10. Рекламный блок вставлен в поток без зарезервированной высоты → скачок
    вёрстки (CLS).
11. Шеринг — четыре ссылки без иконок и `aria-label`.

### Доступность и UI
12. `<div onclick>` вместо ссылок/кнопок, нет skip-link, нет
    `:focus-visible`, дропдаун без клавиатуры и `aria-expanded`.
13. Контраст вторичного текста ниже AA, нет `prefers-reduced-motion`, нет
    тёмной темы.
14. Два разных CSS-бандла (desktop/mobile) и дублирование DOM под мобильные.

### Техника и SEO
15. Три блокирующих CSS с чужого домена, кодировка windows-1251, картинки без
    пресетов — тяжёлый LCP.
16. Нет JSON-LD (`NewsArticle`, `BreadcrumbList`, `WebSite`+`SearchAction`), у
    рубрик нет уникальных `description`, `sitemap.xml` — один плоский файл без
    индекса и без новостного раздела.
17. Inline-сообщения не имеют сущности в модели (в разметке это `<div>`), их
    нельзя ни отфильтровать, ни связать со статьёй.

## 5. Целевая архитектура «Соловья»

**Стек.** Bolt (PHP 8.2+, Plates, Vite, спрайт иконок, `/convert-image`,
`bolt://ui-kit/seo`, `bolt://ui-kit/pagination`) — рендер и ассеты; CakePHP ORM
5 — модель и выборки; Tailwind 4 + Alpine.js + htmx — интерфейс; SQLite — БД.
Монолит, один `vendor/`, один `node_modules/`, код в системном бандле `app/`.

**Слои.**

```
src/Model/Table   — таблицы CakePHP (Articles, Categories, Tags, Sources, FeedItems, Pages)
src/Model/Entity  — сущности с геттерами (reading_time, human_date, url)
src/Support       — подключение БД, AppError, реестр кодов ошибок
app/data          — функции-выборки: articles_latest(), feed_items(), article_by_slug(), search()
app/pages         — маршрут → страница (тонкая, зовёт функции)
app/components    — блоки: шапка, подвал, карточка, строка ленты, крошки, шеринг, алерт
app/fragments     — htmx-фрагменты для «загрузить ещё»
app/client        — Tailwind + Alpine: табы, поиск, тема, прогресс чтения
```

**Маршруты** повторяют оригинал (важно для ссылок и SEO):

```
/                                   главная
/lenta /top /video /smi /tg /opinions /longread /official /hot
/<slug>                             рубрика
/<cat>/<y>/<m>/<d>/<id>.html        карточка
/tema/<slug>                        тема
/istochnik/<slug>                   источник
/poisk?q=…                          свой поиск
/rss.xml /sitemap.xml /robots.txt
/o-nas /kontakty /redakciya /privacy /pravila
```

**Что улучшено (реализовано в этом репозитории)**

| Было | Стало |
|---|---|
| Яндекс-виджет, `/search/` → 404 | свой поиск `/poisk?q=`: LIKE по заголовку, лиду и тексту, подсказки-темы, пустое состояние, `noindex` для выдачи |
| бесконечная прокрутка без URL | пагинация Bolt (`?page=N` / `?pages=1,2`) + «Загрузить ещё» на htmx + обычная ссылка без JS |
| девять табов правой колонки, пустые без AJAX | правая колонка «Сейчас»: алерты, свежее, миниатюры — одним запросом на сервере |
| алерты в общем потоке | сущность `feed_items.kind=alert` + закреплённая полоса под шапкой с временем и источником |
| обрезка по символам | лид режется по границе слова при снятии снимка, заголовок не режется (`line-clamp` в вёрстке) |
| `ЧЧ:ММ` без даты | группировка «Сегодня / Вчера / 20 ноября» + `<time datetime>` |
| нет JSON-LD | `NewsArticle`, `BreadcrumbList`, `WebSite`+`SearchAction` |
| нет тем и источников | страницы `/tema/<slug>` и `/istochnik/<slug>`, теги в карточке |
| карточка без контекста | время чтения, полоса прогресса, «Источник», связанное по теме, переходы «предыдущая/следующая» |
| `<div onclick>` вместо ссылок | ссылки и кнопки, skip-link, `aria-*`, видимый фокус |
| три CSS с чужого домена | один Tailwind-бандл (39 КБ → 8.5 КБ gzip), `/convert-image` + `srcset` + `fetchpriority` у LCP |
| плоский sitemap | `sitemap.xml` с приоритетами и `lastmod`, RSS с `content:encoded` |
| снимок в 61 МБ | исходники уменьшены до 44 МБ (`make media`), отдача через конвертер |

### Проверка доступности

Все пять типов страниц (главная, лента, карточка, поиск, 404) прогнаны
`axe-core` (правила wcag2a/2aa/21a/21aa + best-practice): **0 нарушений**.
Что для этого понадобилось: `<header>` вместо `<div>` (landmark), `sr-only`
`<h2>` перед сетками карточек (порядок заголовков), `aria-label` у двух
поисковых форм (уникальные landmark), `--color-muted` затемнён до `#6b6055`
(5.6:1 на фоне `#f7f4ef`), `aria-label` логотипа убран — видимый текст
самодостаточен.

**Дальше (сознательно не в этой итерации):** тёмная тема, фильтры выдачи
(рубрика/период), галерея в карточке, `ItemList` в разметке лент,
`sitemap_news.xml`, отдельная страница сводки алертов, «сохранить материал».

**Сознательно вне рамок:** комментарии и авторизация (в оригинале их нет),
рекламные слоты, админка (данные — CakePHP ORM + сид), AMP.
